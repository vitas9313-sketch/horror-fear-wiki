# HORROR LAB｜LLM Wiki

## 專案簡介

HORROR LAB｜LLM Wiki 是一個以恐怖文化、恐怖敘事與作品研究為核心的可持續維護知識專案。專案將在查證、引用與著作權規則下，逐步建立適合讀者閱讀、也適合 AI 協作維護的 Wiki 結構。

## 預定成果

- 建立六大知識主題的可追溯 Wiki。
- 建立來源、引用、衝突處理與內容維護流程。
- 在後續獲准階段製作以 Wiki 為基礎的 HTML 簡報。
- 在後續獲准階段設計可解釋的 Graph / Loop 關聯與工作流程。

## 目前進度
