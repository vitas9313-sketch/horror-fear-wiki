# HORROR LAB｜來源到教學簡報 Loop

## Graph 流程

`五篇來源 → AI 整理研究重點 → 人檢查證據與限制 → AI 提出一份整合簡報大綱 → 人確認教學順序 → 逐頁生成 → 逐頁引用檢查 → 一份整合 HTML → 瀏覽器驗收`

## 節點規格

| 節點 | 輸入 | 輸出 | 檢查者 |
|---|---|---|---|
| 來源驗證 | PDF | 合格來源與 SHA-256 | 程式＋人 |
| 研究整理 | 合格來源 | 研究重點、證據、限制 | AI 初整，人核對 |
| 大綱設計 | 研究整理 | 教學順序與頁面目的 | 人 |
| 逐頁生成 | 已確認大綱 | 投影片文字與來源標記 | AI 初整，人逐頁回查 |
| HTML 生成 | 已確認投影片 | 可瀏覽 HTML | 瀏覽器＋人 |

## Graph 生成指令

Graph 的黑暗恐怖哥德風格、節點輸入輸出、人工檢查點與回退規則，見 [graph-generation-prompt.md](./graph-generation-prompt.md)。視覺風格只服務於辨識流程，不得取代文字、箭頭與證據標籤。

## 回退規則

- PDF 不是有效檔案：退回來源驗證。
- 研究主張找不到證據：退回研究整理。
- 大綱不適合初學者：退回大綱設計。
- 投影片主張與來源不一致：退回逐頁生成。
- HTML 顯示或可讀性失敗：退回逐頁生成並重新驗收。

## 本次執行與反思

五個 PDF 均完成標頭、頁數與 SHA-256 檢查，五篇來源各自對應一篇 Wiki 條目。最常出錯的是下載檔案誤收 404/Cloudflare HTML，因此把 PDF 標頭與檔案大小檢查移到 ingest 之前，再計算 hash 與確認頁數。AI 協助整理與改寫；人負責來源核對、大綱順序、逐頁引用與最終瀏覽驗收。
